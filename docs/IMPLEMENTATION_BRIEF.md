# General supervisor → shrimp-pi MVP

Implement this project now. Supervisor can be Codex, Claude, Vibe, human, any shell-capable program. No supervisor SDK dependency. TypeScript on Node >=22.18 using built-in type stripping, node:test, no external dependencies; no compilation required. Project empty and root .git is a read-only placeholder; do NOT initialize git here. Tests create temporary repos.

Implement CLI `node src/cli.ts` and `bin/shrimp-pi` launcher, JSON stdout/errors stderr, commands spawn, status, steer, wait, review, stop, recover, accept. Global --state-dir path default env SHRIMP_PI_HOME or ~/.local/state/shrimp-pi. spawn --repo PATH --task FILE --config FILE. Status etc worker ID. wait --timeout seconds --after revision with sensible timeout JSON; accept records supervisor acceptance never merges. Original operations aliases spawn_worker etc optional. CLI help documents every option.

Architecture: detached per-worker Node daemon owns persistent Pi RPC child, Unix socket for supervisor requests and long-poll wait subscriptions (event-driven, no supervisor polling). Atomic state.json with revision, meaningful transitions CREATED RUNNING REVIEW_REQUIRED BLOCKED COMPLETED FAILED STOPPED. COMPLETED only explicit supervisor accept after review. Unique worker directories. CLI spawn creates isolated git worktree on new branch from HEAD (requires committed repo; refuse dirty target? can permit dirty source because base is HEAD but document). No auto merge or deletion. base commit saved. Diff includes worker commits vs original base plus uncommitted/untracked files. review concise report plus diff path, raw logs separate; independent git data, agent claims labeled. Reports stored outside workspace and supervisor reviews independent git. Safe IDs validate UUID to prevent traversal. Socket mode 0600 directory 0700. Serialize mutations and handle races. wait returns existing attention state immediately unless --after revision requests a later event. Timeout bounded JSON. Persist revision across restarts.

Pi 1.5.0 installed. Config JSON user-supplied e.g. piCommand array ['/opt/node/bin/node','/opt/pi/node_modules/@earendil-works/pi-coding-agent/dist/bundle/cli.js']; provider/model via isolated generated models.json (endpoint, apiKey env ref, API openai-completions); don't load personal credentials/extensions/settings/project extensions. PI_CODING_AGENT_DIR isolated. Only minimal env allowlist; explicit env key name for endpoint token; no copying arbitrary secrets. node may not be on system PATH: current process executable directory should be prepended.

Isolation: Linux bubblewrap default, fail closed if absent. Whitelist /usr read-only, /lib and /lib64 symlinks to usr paths as needed, /etc read-only (prefer minimal DNS, certificates, passwd), /dev, /proc, tmpfs /tmp, isolated HOME; bind isolated worktree writable and worker agent/session dir writable, Pi runtime paths declared config runtimePaths read-only plus current Node path. No credentials sockets, inherited env; network available to inference only limitation document network not restricted. macOS default fail closed with configurable explicit external sandbox launcher or documented unsupported; no silent unsandboxed fallback. Config sandbox disabled only explicit flag accepted for trusted caller, clearly surfaced.

RPC protocol verified from installed official docs: strict LF-delimited JSONL (do NOT use readline; U+2028 is valid inside JSON); correlate by id, handle backpressure stdout/stderr, subscribe before sending prompt. `prompt` acceptance is NOT completion; `agent_end` is NOT completion. `agent_settled` marks final idle after retries. prompt response disposition started/queued/handled. During RUNNING steer by prompt streamingBehavior:'steer'; idle prompt restarts same session. message_end assistant contains text blocks, usage, stopReason/errorMessage. tool_execution_end contains isError durationMs toolName result; capture commands/tests evidence but don't invent pass counts. Track failed tool attempts, repeated failures threshold configurable -> abort and BLOCKED carefully avoid abort settler overwrite. On settled validate final structured JSON agent report (workCompleted, tests, decisions, outstandingProblems, questions, status review|blocked|checkpoint). Prompt worker to return report as final answer (no file in workspace). Never treat missing report as success. provider failures become FAILED. Unexpected daemon/process death -> CLI diagnoses lost connection, marks FAILED explicitly; recover lock-exclusive relaunch reopens same session file, reports interrupted work, does NOT silently replay original task or tool commands.
